# Morya FarmOS

Starter structure for a collaborative React + Express + MySQL dairy farm application.

## Setup

1. In `client`: `npm.cmd install` then `npm.cmd run dev` (PowerShell).
2. In `server`: `npm.cmd install`, copy `.env.example` to `.env`, then `npm.cmd run dev`.
3. Visit http://localhost:5000/api/test for backend test.

MySQL integration and features are placeholders for the next development phases. Never commit `.env`.
